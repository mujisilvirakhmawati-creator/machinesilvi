# Dashboard Analisis Clustering Data Kesehatan

## 🎯 Overview
Dashboard interaktif untuk analisis clustering data kesehatan menggunakan berbagai algoritma machine learning.

## 🚀 Fitur Utama
- 8 tab navigasi lengkap
- 5 algoritma clustering (K-Means, GMM, Hierarchical, MeanShift, Spectral)
- Visualisasi interaktif dengan Plotly
- Prediksi data baru
- Interface user-friendly

## 📋 Prerequisites
- Python 3.8+
- Library di requirements.txt

## 🛠️ Installation
```bash
pip install -r requirements.txt
